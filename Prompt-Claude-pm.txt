how can I test the app frmo my side?myself from browser?

Option 1 — Frontend only (quickest)

  Run from frontend/:
  npm run dev
  Then open http://127.0.0.1:3000 in your browser. Login with user / password. This gives you the full UI (login, board,
  drag-drop, add/delete cards), but board state is not yet persisted to the backend (Phase 7 is still pending).

  Option 2 — Full stack via Docker (closest to production)

  From PowerShell at the project root:
  ./scripts/start.ps1
  Then open http://localhost:8000. This builds the static frontend and serves everything through FastAPI. Board state will
  be read/written to the SQLite DB, but since the frontend isn't yet wired to call the API (Phase 7 pending), the board
  still shows the hardcoded initialData.

  Recommendation: Use Option 1 for now. It's faster to start and lets you test the UI. Once Phase 7 (frontend/backend
  integration) is done, Option 2 will be the meaningful full-stack test.

  What to test

  1. Login
  - You should see the login form, not the board
  - Enter user / password → board should appear with 5 columns and 8 cards
  - Try a wrong password → expect an error message

  2. Board loads from the backend (Phase 7 core)
  - Open DevTools → Network tab → filter by /api/board
  - Reload the page, sign in again → you should see a GET /api/board request returning 200 with your board data

  3. Add a card and reload
  - Click "Add a card" in any column → fill in a title → click "Add Card"
  - Hard reload the page (Ctrl+Shift+R) → sign in again
  - The new card should still be there (it was saved to the backend)

  4. Drag a card between columns
  - Drag any card from one column to another
  - Hard reload → sign in → the card should be in its new column

  5. Rename a column

  - Hard reload → sign in → the new name should persist

  6. Delete a card
  - Hover over a card → click the delete button
  - Hard reload → sign in → card should be gone
