how can I test the app frmo my side?myself from browser?

Option 1 — Frontend only (quickest)

  Run from frontend/:
  npm run dev
  Then open http://127.0.0.1:3000 in your browser. Login with user / password. This gives you the full UI (login, board,
  drag-drop, add/delete cards), but board state is not yet persisted to the backend (Phase 7 is still pending).

  Option 2 — Full stack via Docker (closest to production)

  From PowerShell at the project root:
  ./scripts/start.ps1
  Then open http://localhost:8000. This builds the static frontend and serves everything through FastAPI. Board state will
  be read/written to the SQLite DB, but since the frontend isn't yet wired to call the API (Phase 7 pending), the board
  still shows the hardcoded initialData.

  Recommendation: Use Option 1 for now. It's faster to start and lets you test the UI. Once Phase 7 (frontend/backend
  integration) is done, Option 2 will be the meaningful full-stack test.

How do I test the application from browser?

You need two terminals running simultaneously for the full-stack experience (UI + AI sidebar):
                                
  Terminal 1 — Backend (from project root D:\Rahul\Tech\VibeCoding\Claude\Projects\pm):
  .venv\Scripts\uvicorn backend.app:app --port 8000 --reload

  Terminal 2 — Frontend (from frontend\):
  npm run dev

  Then open http://127.0.0.1:3000 in your browser.

  ---
  What to test:

  1. Login — enter user / password, click Sign In
  2. Add a card — click "Add a card" in any column, fill title + details, submit
  3. Edit a card — click a card to open the edit modal, change title/details, save
  4. Drag a card — drag a card to a different column
  5. Rename a column — click the column title input, change it, click elsewhere
  6. Persist across reload — make changes, reload the page, confirm they're still there
  7. AI sidebar — click "Open chat" in the top-right, then try:
    - "How many cards are in Backlog?" (read-only query)
    - "Add a card called Deploy v1 to the Done column" (board update)
    - Confirm the board updates automatically when AI returns a change
  8. Logout — click Logout (top-right), confirm you're returned to the login screen

  For the AI to work, ensure you have an OPENROUTER_API_KEY set in a .env file at the project root:
  OPENROUTER_API_KEY=your-key-here
